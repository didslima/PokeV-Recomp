# PokeV-Recomp v0.1.1-rc.1 (Release Candidate / Pre-release)

> **Testing Pre-release:** This is a **Release Candidate** intended solely to validate the **Linux AppImage Auto-Updater (Phase B)** against a real GitHub Pre-release. **Regular users should stay on the latest stable release (`v0.1.0`).**

## Purpose
Validate end-to-end Linux AppImage updates from a Phase A/B build (`v0.1.0` + `#54` / `#55`) to `v0.1.1-rc.1` without exposing this candidate on the stable `/releases/latest` channel.

## What's Included
- **Update Checker (Phase A, #54):** Asynchronous GitHub release check, release notes viewer, offline/rate-limit handling, and RecompLauncher suppression.
- **Linux AppImage Auto-Updater (Phase B, #55):**
  - Download with live progress and cancellation (`Cancel Download`).
  - Mandatory `SHA256SUMS` verification via `CacheSha256`.
  - Detached external `/bin/sh` updater with hardlink/copy backup (`.bak`), atomic replacement (`mv -f`), automatic rollback, PID-timeout guard, and relaunch.
- **Opt-In Pre-release Channel (`LARECOMP_UPDATE_PRERELEASE=1`):** Queries `/releases?per_page=10` and accepts `-rc.N` pre-releases only when `LARECOMP_UPDATE_PRERELEASE=1` is set.

## How to Test (Linux AppImage)
1. Launch a base AppImage built from `main` (with Phases A & B) using:
   ```bash
   LARECOMP_UPDATE_PRERELEASE=1 ./PokeV-Recomp-linux-x86_64.AppImage
   ```
2. Open the release notes modal, click **Download & Update**, confirm, and click **Install & Restart**.
3. Verify the relaunched AppImage reports `v0.1.1-rc.1` and that saves, `larecomp.ini`, mods, and `extracted/` remain untouched.
