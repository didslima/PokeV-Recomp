# PokeV-Recomp v0.2.1

## Highlights

### RecompLauncher DLC Support (#70, #72)
- **Optional DLC slots in `recomplauncher.json`:** Added `dlc1` and `dlc2` (`role: "dlc"`, `optional: true`, `.nsp` / `.xci` with `requires: ["keys"]`) and `--dlc={input:dlc1}` / `--dlc={input:dlc2}` arguments in `prepare.args`.
- **Incremental DLC import (`--aoc-only`):** `tools/zaimport` now supports importing DLC packages into `extracted/aoc/<title_id>.bin` without requiring or re-extracting the base game `romfs.bin`.
- **Existing installation & save safety:** `launcher_prepare()` detects newly added or updated DLC packages via `aoc/.dlc_stamp` instead of short-circuiting with `Already built`, preserves existing installations when inputs are unchanged, includes `aoc` in `GAME_FILES` for full cleanup, and never touches `save/save_0`.

### Ultrawide Cutscene Transition Fix (#71)
- **GPU-owned fullscreen snapshot handling:** Avoids 16:9 boxing GPU-owned fullscreen transition snapshots so in-engine cutscene transitions render cleanly on ultrawide displays.

## Upgrade & Recompilation Notice

- **`GAMELIB_ID` unchanged from `v0.2.0`** (`86c55c7268f8418d`): No game-code recompilation needed when upgrading from `v0.2.0`.
- **`SHADER_TRANSLATOR_ID` unchanged:** Existing shader caches remain compatible.
- **Saves, settings, and mods** are preserved and remain compatible.
